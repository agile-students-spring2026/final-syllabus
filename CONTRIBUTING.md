# Contributing to Syllabus+

This file covers how we work together as a team. Read through it before getting started.

---

## Communication

We use Discord as our main way of staying in touch. Everyone should check it regularly and respond within 24 hours. If something urgent comes up, tag the person directly.

We have standups twice a week. If you can't make it, give the team a heads up beforehand and drop your update in Discord (what you did, what you're working on, any blockers).

---

## What's expected each sprint

At the start of each sprint we'll divide up the work and track it on the task board. Everyone is expected to complete what they signed up for by the end of the sprint. If you're stuck or falling behind, say something early — don't wait until the last minute.

---

## Working with the GitHub repo

- Work on a separate branch, not directly on `main`
- Write commit messages that actually describe what you did
- Open a pull request when you're done and get at least one teammate to review it before merging
- Don't merge your own PR

---

## If someone isn't pulling their weight

We know conflict happens. Here's how we agreed to handle it:

**First** — whoever notices the problem will reach out to that person directly on Discord. We'll let them know what's going on and try to sort it out between ourselves first.

**If that doesn't work before the next standup** — the team will:
- Let the admins know what's happening
- Have other teammates pick up the slack so the project doesn't stall
- Keep the person in the loop by posting standup notes and updates to Discord
- Welcome them back if they want to get involved again later

One thing we all agreed on: we're not going to wait more than 2 standups for someone to finish their tasks. The project keeps moving.

---

## General stuff

- Be respectful, communicate openly, and don't ghost the team
- If you disagree with something, bring it up — decisions are made together
- Everyone's time matters, so be on time or give notice
